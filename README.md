# ArtSeek project page

Static site (HTML, CSS, JavaScript; no build step) served by GitHub Pages from this branch.

- `index.html`: the page.
- `static/js/data.js`: real ArtSeek and Qwen2.5-VL-32B outputs shown in the demo and in the blind test, and the results of the paper.
- `static/js/main.js`: demo replay, charts (plain SVG) and interactions.
- `static/img/`: paintings (public domain), retrieved Wikimedia images (see the page footer for licences) and figures from the paper.

Preview locally with `python -m http.server` in this folder. The code is on the [`main`](https://github.com/cilabuniba/artseek) branch.
